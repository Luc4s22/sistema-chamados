# 📋 Sistema de Chamados

Sistema web para gerenciamento de Ordens de Serviço (O.S.) e chamados internos.

## 🚀 Tecnologias

* HTML5
* CSS3
* JavaScript
* Python
* Flask
* MySQL

## 📌 Funcionalidades

* Cadastro de chamados
* Consulta de chamados
* Pesquisa por setor e número
* Edição de chamados
* Conclusão de chamados
* Exclusão de chamados
* Controle de status
* Contadores de chamados
* Armazenamento em banco de dados MySQL
